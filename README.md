## Proyectos destacados

### MuseCode

Asistente de programación para **macOS 14 o posterior** (Apple Silicon). Trabaja en el Mac con un modelo local de [Ollama](https://ollama.com): lee el proyecto, propone cambios, los aplica, compila y ejecuta los tests. Antes de modificar archivos o ejecutar código muestra lo que va a hacer y espera aprobación.

La última versión pública es **1.0.12**, firmada con Developer ID y notarizada por Apple. El código fuente no es público.

- **Stack:** Swift, SwiftUI, Ollama; runtime de navegador en JavaScript
- **[Repositorio de descargas](https://github.com/C3t3lina/MuseCode-Releases)** · **[Última versión](https://github.com/C3t3lina/MuseCode-Releases/releases/latest)**

### Darija Unified

Traductor y material de aprendizaje de **darija** (árabe marroquí) y **español** para iPhone y iPad (iOS 17 o posterior). Incluye diccionario, frases con audio de pronunciación, reconocimiento de voz (principalmente con WhisperKit en el dispositivo) y síntesis de voz. La interfaz está en español.

La app es **gratuita**, sin compras integradas, sin publicidad y sin cuenta. El código fuente de la app no está en este perfil; sí lo está su página pública de soporte.

- **Stack documentado:** iOS, WhisperKit (reconocimiento de voz en el dispositivo)
- **[Página de soporte](https://c3t3lina.github.io/darija-unified-support/)** · **[Repositorio](https://github.com/C3t3lina/darija-unified-support)**

### Aprende Darija

App Android en Kotlin para aprender darija marroquí: vocabulario, diálogos interactivos, práctica de pronunciación y un tutor con inteligencia artificial (API de Gemini, proyecto exportado desde Google AI Studio).

- **Stack:** Kotlin, Android, Gemini API
- **[Repositorio](https://github.com/C3t3lina/Aprende-darija-marroqui)**

## Otros repositorios públicos

### [OmniSync-AI](https://github.com/C3t3lina/OmniSync-AI)

App Android en Kotlin («Asistente Personal IA»): redacción de correos, guías de estudio, análisis de extractos bancarios y gestión local de datos. También exportada desde Google AI Studio, con API de Gemini.

### [parallels-clone](https://github.com/C3t3lina/parallels-clone)

App para macOS (Swift / SwiftUI) y agente para Windows para gestionar máquinas virtuales con `Virtualization.framework`: configuración de CPU, RAM y disco, más la estructura para carpetas compartidas, red y portapapeles. El propio README indica que la comunicación SPICE real, el agente de Windows, el montaje de carpetas y la sincronización de portapapeles aún no están terminados.

### [quemu-ios-android](https://github.com/C3t3lina/quemu-ios-android)

Proyecto de investigación en Kotlin y C: experimentar con una VM de iOS/macOS ARM64 en Android mediante QEMU (TCG, sin root). No incluye imágenes de iOS ni de macOS.

### [ios-vm-research-1](https://github.com/C3t3lina/ios-vm-research-1)

Investigación en C sobre emulación de XNU/iOS en QEMU (objetivo T8030 / iPhone 11), centrada en el análisis y la mutación del Apple Device Tree. Se apoya en proyectos open source ya existentes. No distribuye firmware de Apple.
